# I just wanted a login form

You start with a login form. You end with 14 identity providers and a service mesh. A satirical scrollytelling essay on modern auth/authz — passwords, OAuth, SAML, RBAC, ABAC, ReBAC, and the service mesh at the bottom of the swamp.

- Read it: <https://kanywst.github.io/i-just-wanted-a-login-form/>
- Background: [I Just Wanted a Login Form: The "Swamp" of Complexity in the Modern Auth Ecosystem](https://dev.to/kanywst/i-just-wanted-a-login-form-the-swamp-of-complexity-in-the-modern-auth-ecosystem-23pm) (dev.to)

## Run locally

```bash
npm ci
npm run dev
```

Static site built with React, Vite, TypeScript, and Tailwind CSS. Deployed to GitHub Pages on push to `main`.
